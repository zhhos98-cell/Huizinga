# Frozen review rounds

This directory preserves the sequential review-round logs moved from the top level of `review/` on 2026-09-05.

These files are **historical workflow provenance, not current review authority**. They record how the closed corpus review progressed across successive 5-PDF / 6-PDF rounds, the tail pass, backward PDF-correction rounds, and the old `PROGRESS.md` state.

For current corpus status use:

- `../../review/CURRENT_CALIBRATION_STATUS.md`
- `../../review/CORE_THEME_HITS.md`
- `../../FINAL_CLOSURE_2026-08-30.md`
- `../../CLOSURE_STATE_2026-08-30.json`

For a specific chunk, use `../../review/chunk_*/` and the corresponding correction/source layer.

Do not resume work from a numbered `ROUND_*` file merely because it contains an unfinished-looking local instruction. Those local states were superseded by later rounds and the final corpus closure. Reopen a chunk only when the current article exposes a bounded factual/source gap or when new source images become available.

The 2026-09-05 move preserved the original blobs; this directory is a path-level freeze, not a rewriting or consolidation of the historical logs.
