# Frozen one-off article patch scripts

These scripts record the sequential 4–5 September 2026 editing passes that produced earlier states of Draft 04, AGENTS.md and research ledgers. They are preserved for provenance only.

They are **not reusable tooling** and should not be run against the current canonical draft. Later article restructuring and source controls supersede the exact text states expected by these scripts.

Active reusable scripts remain in `../../../scripts/`:

- `apply_pdf_corrections.py`;
- `build_pdf_verification_log.py`;
- `scan_dbnl_vw_article.py`;
- `review_dbnl_vw_units_1921_1933.py`.

If a historical patch must be inspected, read it as an intellectual/version-control record; do not execute it unless deliberately reconstructing that historical commit state.
